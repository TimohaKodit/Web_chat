# Web Chat

Веб-мессенджер с обменом сообщениями в реальном времени через WebSocket.

Пет-проект, который развивается до полноценного приложения: с авторизацией,
хранением истории в базе данных и деплоем на сервер.

## Стек

- **Python 3.12** + **FastAPI** — веб-фреймворк
- **uvicorn** — ASGI-сервер
- **WebSocket** — двусторонняя связь между сервером и клиентами
- **PostgreSQL** — хранение пользователей и истории *(в планах)*

## Возможности

- [x] Групповой чат: сообщение от одного клиента рассылается всем подключённым
- [x] Корректная обработка отключения клиента
- [ ] Имена пользователей и системные сообщения о входе/выходе
- [ ] История сообщений в базе данных
- [ ] Регистрация и авторизация
- [ ] Личные чаты и комнаты

## Запуск

```powershell
# создать и активировать виртуальное окружение
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# установить зависимости
pip install -r requirements.txt

# запустить сервер
uvicorn app.main:app --reload
```

Запускать из корня проекта — путь `app.main` считается относительно него.

После старта:
- `http://127.0.0.1:8000/` — интерфейс чата
- `http://127.0.0.1:8000/docs` — автодокументация API

## Как это работает

Клиент открывает WebSocket-соединение с `/ws`. Сервер принимает его и добавляет
в список активных подключений (`ConnectionManager`). Когда от любого клиента
приходит сообщение, сервер проходит по списку и отправляет его всем.

При отключении клиента срабатывает `WebSocketDisconnect`, и соединение удаляется
из списка.

## Протокол

На текущий момент по сокету передаётся простой текст.

В работе — переход на JSON, чтобы различать типы сообщений и знать автора:

**Клиент → сервер**
```json
{"text": "привет"}
```

**Сервер → клиенты**
```json
{"type": "message", "user": "Вася", "text": "привет"}
{"type": "system",  "text": "Вася вошёл в чат"}
```

Поле `user` проставляет сервер — клиент не может отправить чужое имя.

> Авторизации пока нет: имя не проверяется.
